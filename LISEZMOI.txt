=====================================
ANONYMISEUR DE DOCUMENTS - INSTALLATION
=====================================

PREMIERE INSTALLATION :
-----------------------
1. Extraire le fichier ZIP dans un dossier de votre choix
   (ex : C:\Anonymiseur)

2. Double-cliquer sur "install_and_run.bat"

3. IMPORTANT : Si Python n'est pas installe :
   - Le script va le telecharger automatiquement
   - Une fois Python installe, FERMEZ la fenetre
   - RELANCEZ "install_and_run.bat" une deuxieme fois

4. L'installation prend 2-5 minutes
   - Un fichier de log est cree dans le dossier "logs"
   - En cas d'erreur, consultez ce fichier

5. L'application demarre automatiquement dans votre navigateur

UTILISATIONS SUIVANTES :
-----------------------
Utilisez le raccourci "Anonymiseur" sur votre bureau
OU double-cliquez sur "run_app.bat"

EN CAS DE PROBLEME :
--------------------
1. Verifiez le fichier : logs\install_and_run.log
2. Verifiez que vous avez une connexion internet
3. Verifiez que votre antivirus n'a pas bloque l'installation
4. Essayez d'executer en tant qu'administrateur :
   Clic droit sur install_and_run.bat > Executer en tant qu'administrateur
