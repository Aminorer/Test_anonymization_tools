🛡️ ANONYMISEUR DE DOCUMENTS - MODE D'EMPLOI
═══════════════════════════════════════════════

📌 PREMIÈRE UTILISATION
-----------------------
1. Extraire le fichier ZIP dans un dossier (ex : C:\Anonymiseur)
2. Double-cliquer sur "install_and_run.bat"
3. Attendre 2 à 5 minutes le temps de l'installation automatique
4. L'application s'ouvre automatiquement dans votre navigateur

⚡ UTILISATIONS SUIVANTES
-----------------------
→ Double-cliquer sur le raccourci "Anonymiseur" créé sur le bureau
OU
→ Double-cliquer sur "run_app.bat" dans le dossier du projet

📁 DOSSIERS CRÉÉS AUTOMATIQUEMENT
---------------------------------
- temp : fichiers temporaires
- logs : journaux de fonctionnement
- exports : documents anonymisés exportés
- data : données persistantes

❓ EN CAS DE PROBLÈME
--------------------
1. Vérifiez qu'aucun antivirus ne bloque Python ou Streamlit
2. Consultez le journal détaillé : ouvrir le fichier `logs\install_and_run.log` pour connaître l'étape qui a échoué
3. Redémarrez l'ordinateur puis relancez "install_and_run.bat"
4. En cas d'échec de l'installation de Python, relancez le script en tant qu'administrateur (clic droit > Exécuter en tant qu'administrateur)
